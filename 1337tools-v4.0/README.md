# 1337tools v4.0 — FIELD prototype

The editor is no longer the product. It is now COMPOSE, the final assembly area.

## New default tool: FIELD
- One source image becomes a procedural visual system.
- Drag the yellow field point directly on canvas.
- Three rule interpretations: PULL, VORTEX, WAVE.
- Only four macro controls: Amount, Scale, Force, Order↔Chaos.
- RANDOMIZE SYSTEM generates a new parameter state.
- LOCK keeps individual macro parameters while randomizing the rest.
- REROLL SEED mutates the result without rebuilding the control state.
- Export FIELD directly as PNG or SEND TO COMPOSE as a flattened image layer.
- Clipboard paste works in FIELD for image blobs/files.

## Product direction
INPUT → RULE → RANDOM → LOCK → REROLL → OUTPUT

COMPOSE remains available, but it is deliberately secondary.
