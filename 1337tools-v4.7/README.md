# 1337tools v4.7

FIELD-focused cleanup.

- TYPE is removed from the product for now.
- Main directions are FIELD and EDITOR.
- Fixed browser default drag/drop behavior: dropping an image no longer opens it as a new browser tab.
- FIELD accepts a dropped local image anywhere on its workspace, plus the existing file button and clipboard paste.
- Added FIELD FX: blend modes, contrast, mono, invert, hue, blur and deterministic micro-noise.
- RANDOMIZE SYSTEM now also mutates FX, so results diverge much more strongly without manual slider work.
- EDITOR remains the full composition/editor tool.
