# 1337tools v4.37

Interaction cleanup release built on the v4.36 catalog direction. No new tools.

## Changes
- restored the stable v4.31 live entry animation exactly
- catalog keeps only `visual processing system`; the secondary tagline is removed
- tool-name hover effects render in white on every card
- SLICE uses the same glass card surface as every other tool; no yellow card state remains
- HUD action buttons stay transparent; yellow is used as a text accent instead of a filled button surface
- RANDOMIZE/REROLL no longer use raised or filled backing
- decorative stripes/grid overlays inside the working UI are removed
- sliders are static and conventional: one simple track, one square thumb, no shape alternation or hover animation
- brand tracking variables from v4.34 remain shared, including the 1→3 spacing used on Credits

## Stability
FIELD / SLICE / ASCII / ECHO / EDITOR behavior, ratios, PNG/PNG alpha export, CONTINUE flow, image-load guards, STAMP fill/stroke controls, and the approved Credits copy remain intact.
