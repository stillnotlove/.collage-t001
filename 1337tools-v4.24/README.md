## New tool — ECHO
A recursive repetition / feedback-style image tool.

Modes:
- TRAIL — progressive translated copies
- TUNNEL — recursive scale/depth copies
- ORBIT — repeated copies distributed around a rotating path

Controls:
- Copies
- Scale step
- Offset X / Y
- Rotation
- Fade
- Spread
- Chaos
- Blend mode
- Source image scale / X / Y
- Canvas ratio and background

ECHO supports drag/drop, paste, PNG, transparent PNG, Send to Editor, CONTINUE, collapsible HUD groups and the existing process trail.
