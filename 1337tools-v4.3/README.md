# 1337tools v4.3

Three distinct directions instead of one all-purpose editor.

## Menu
- `01 FIELD` — procedural image field system.
- `02 EDITOR` — the original layer-based editor kept as its own tool.
- `03 TYPE` — a new experimental type / glyph lab.

## EDITOR
- Keeps the original layers, images, text, shapes, repeat, stamp, effects and export workflow.
- Adds `REMOVE BG β` in Image Lab, with restore/retry behavior.
- FIELD and TYPE outputs can be sent directly into EDITOR as transparent PNG layers.

## TYPE v1
- WORD and GLYPH modes.
- Font family, weight, size, tracking, width, height and slant.
- Baseline mutation, rotation, chaos and glyph copies.
- Fill + outline controls.
- `RANDOMIZE LETTERS` and `REROLL SEED`.
- Transparent PNG export or `SEND TO EDITOR`.

## Shell
- Entry remains almost empty: only the 1337tools mark.
- Increased tracking on the large `tools` wordmark.
- Click/tap or keyboard input enters the tool index.
