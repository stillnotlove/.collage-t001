# Collage Tool v3

Experimental collage/poster playground.

Core: Image + Type + Shape → Transform → Repeat → Distress → Randomize

Included:
- persistent selection
- resize handles + rotate handle
- Shift resize preserves aspect ratio
- Undo / Redo
- Delete / Cmd/Ctrl+D shortcuts
- Layers with hide / lock / reorder
- Google Fonts with Cyrillic and handwritten families
- Type Lab: size, weight, tracking, line-height, stretch X/Y, outline
- Stamp tool for words and shapes
- Repeat / Pattern + Order ↔ Chaos
- Image Lab adjustments
- Distress: threshold, grain, noise, scratches, halftone, xerox, fade
- Blend modes
- Generate variation
- PNG/JPEG export
- local uploads

Art Pavlushin fonts are intentionally not bundled until a specific font's web/redistribution license is verified.

For Vercel set Root Directory to `collage-tool-v3`.
