# 1337tools v4.32

A visual-system pass based on the stillnotlove direction: experimental publishing tool, desktop/editorial logic, controlled new-ugly composition.

## Visual changes
- transparent tool cards so the oversized active word remains visible behind the catalog
- odd final card spans the full catalog width; the layout returns to pairs automatically as more tools are added
- flatter, less technical catalog chrome and larger editorial typography
- HUD accordions behave like highlighted editorial captions rather than instrumentation panels
- sliders redesigned as simple graphic lines with oversized art-object handles; no ruler ticks
- alternating circular / square handles introduce controlled irregularity without changing interaction
- control labels use normal-case Helvetica-style typography rather than technical uppercase tracking
- values are larger and float as type instead of living in boxed number fields
- primary HUD actions use offset-print style shadows and stronger block composition
- continued cleanup of mono/technical typography in the user-facing chrome
