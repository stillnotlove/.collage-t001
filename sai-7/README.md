# SAI — Incense & Objects (v7)

Minimal branded concept website, deployed independently from 1337tools.

## Build

```bash
npm run check
npm run build
```

Deploy to a **new dedicated GitHub repository / Vercel project**.
- Framework: `Other`
- Root: `./`
- Build: `npm run build`
- Output: `dist`

## Page structure
- Click original SAI logo on intro to enter collection.
- Collection: compact equal rectangular cards, all 6 incense SKUs share one exact supplied image.
- Philosophy: multi-section scroll, updated steel photo and smaller imagery/text.
- Bag: visual demo only; checkout is not connected to payments.

## Key assets
- `public/assets/sticks-approved.png` — exact user-approved four incense sticks, reused in all six scent products
- `public/assets/matches-approved.png` — approved matchbox photograph
- `public/assets/holder-white-smoke-approved.png` — approved holder with smoke, for the collection card
