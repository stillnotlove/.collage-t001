# 1337tools v4.36

A stronger stillnotlove visual-system pass: controlled excess, experimental publishing, layered editorial chaos, and a less dashboard-like HUD. No new tools were added in this release.

## Catalog / visual system
- layered catalog background with irregular acid / paper-like surfaces, outline loops, rails and oversized typography
- background separated into distinct depth layers so it stays intentionally busy without flattening the navigation into noise
- tool cards are still functional, but no longer share one rigid rectangular silhouette
- removed decorative corner icons from tool cards
- cards use asymmetric cuts, radii and proportions while preserving clear hit areas
- editorial micro-copy added to each tool without renaming the tools
- active background word remains present but is reduced to one controlled layer instead of competing with every card
- CREDITS remains the calm endpoint and keeps the approved wording

## HUD
- translucent HUD/workspace chrome so the oversized tool word can live behind the interface
- large background tool names for FIELD / SLICE / ASCII / ECHO / EDITOR
- accordions use graphic caption marks rather than terminal-like section treatment
- sliders no longer use ruler ticks; they use a simple line plus asymmetric art-object handles
- alternating handle shapes keep the interface irregular without changing interaction behavior
- buttons retain strong print-block hierarchy but stay usable

## Entry animation
- expanded transition grammar with more scan / outline / tiles / echo combinations
- longer clean holds and slower rebuild phases
- stronger clean-word ghost during aggressive processing so `1337tools` remains readable
- completed stages continue to use the existing cache optimization

## Stability
Previous tool functionality, ratios, PNG / PNG alpha exports, CONTINUE, image-load guards, ECHO background removal, STAMP fill/stroke controls and default `1337` stamp text remain intact.
