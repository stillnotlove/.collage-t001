# Collage Tool v2 

Добавлено:

- изображения из компьютера
- drag & drop
- remote image proxy
- формы: rectangle / circle / ellipse / triangle / star / cross / line
- текстовые слои
- blend modes
- distress: grain / noise / scratches / threshold / fade
- opacity / width / height / rotation
- duplicate / front / back / delete
- shuffle

## Deploy

Проект рассчитан на Next.js и Vercel.

Если репозиторий уже подключен к Vercel:
1. заменить файлы проекта файлами из этого архива
2. commit в `main`
3. Vercel автоматически сделает новый deployment
